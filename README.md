Statically compiled minimal FFmpeg (v6.1) binaries for Windows and Mac built using Github Actions (and written using Claude.ai).

It includes :
  - `ffmpeg-mac` — macOS Universal (arm64 + x86_64)
  - `ffmpeg-win.exe` — Windows x64
            
Included Codecs : AAC, MP3, Opus, Vorbis, FLAC, PCM
Containers : MP4, MOV, MKV, AVI, FLV, OGG, WAV

I needed to embark a small version to extract audio in a Node4Max Project.
